Examples Notebooks
==================

Example notebooks and tutorials providing practical demonstration of BART-Survival functionality:

- `01_quickstart_causal_survival.ipynb <https://github.com/CDCgov/BART-Survival/blob/main/examples/01_quickstart_causal_survival.ipynb>`_: End-to-end tutorial demonstrating synthetic cohort simulation, SurvBART model fitting, cumulative survival curves, feature importance, and support-audited Causal G-Computation.
- `example1.ipynb <https://github.com/CDCgov/BART-Survival/blob/main/examples/example1.ipynb>`_: Step-by-step synthetic Weibull simulation, TAD/PAD data transformation, and continuous survival prediction.
- `example2.ipynb <https://github.com/CDCgov/BART-Survival/blob/main/examples/example2.ipynb>`_: Application of discrete-time SurvBART to the open Rossi recidivism benchmark dataset.
